Core Modules

6 โมดูลหลัก ครบในระบบเดียว

ออกแบบมาเพื่องานรักษาความปลอดภัยโดยเฉพาะ พร้อมใช้งานได้ทันที

01

ระบบลงเวลา & ยืนยันตัวตน

Time & Identity Verification

LINE LIFF + AI Bot ลงเวลาเข้า-ออกงาน Real-Time ยืนยันตัวตนด้วยรหัสพนักงาน

  • บันทึกเข้า-ออกงานอัตโนมัติ
  • ประวัติการลงเวลาย้อนหลัง
  • แจ้งเตือนผ่าน LINE ทันที
02

Dashboard จัดการพนักงาน

Supervisor Dashboard

ดูสถานะกำลังพลทุกหน่วยงานแบบ Real-Time กี่คนมา กี่คนขาด กี่คนลา รู้ได้ทันที

  • ภาพรวมทุกหน่วยงานในหน้าเดียว
  • Export รายงาน Excel ได้ทันที
  • กรองข้อมูลตามวันและหน่วยงาน
03

OP05 รายงานพบผู้ว่าจ้าง

Client Visit Report

บันทึกการเข้าพบผู้ว่าจ้างพร้อม Checklist มาตรฐาน 4 ด้าน เลขที่เอกสารอัตโนมัติ

  • ด้านกำลังพล ระเบียบวินัย คุณภาพ อุปกรณ์
  • Progress Bar ติดตามความคืบหน้า
  • Timestamp บันทึกแม่นยำ
04

OP06 รายงานรวมแถว

Morning / Evening Roll Call

บันทึกการรวมแถวผลัดเช้า-เย็น ระบุผู้นำแถวและรายชื่อผู้เข้าร่วม

  • ผลัดเช้า 06:00–18:00 น.
  • ผลัดเย็น 18:00–06:00 น.
  • บันทึกผู้เข้าร่วมทุกคน
05

OP07 รายงานอบรมประจำเดือน

Monthly Training Report

บันทึกการอบรมพนักงาน ครบถ้วนตามมาตรฐาน 9 หมวดหัวข้อ

  • กฎหมาย SOP การปฐมพยาบาล และอื่นๆ
  • บันทึกวิทยากรและผู้เข้าร่วม
  • สรุปรายงานประจำเดือน
06

FMQC-02 ตรวจเยี่ยมหน่วยงาน

Site Inspection Module

Checklist ตรวจมาตรฐานสนาม ผ่าน / กำชับ / พบปัญหา เลขที่เอกสารอัตโนมัติ

  • กำลังพล การแต่งกาย การจราจร
  • ตรวจช่วงวันหยุด การเดินตรวจพื้นที่
  • บันทึกโดย Supervisor ได้ทันที
